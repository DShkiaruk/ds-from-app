# ds-from-app — Plan 2 of 3: the Workbench repo

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `node scripts/scaffold.mjs workbench <repo>` turns an extraction repo (captures, tokens, the designer's decisions) into a working Workbench project: tokens as generated CSS variables, Storybook with Foundations, the test-flow spec, the harness files (AGENTS.md, PROMPT_plan/build, FRONTEND.md, DESIGN.md, PROJECT.md), a Stop hook, CI, and seven gates — `npm run check:fast` green on a fresh project, `npm run check` green once the flow is built.

**Architecture:** Everything the product repo runs lives in `templates/workbench/` and is copied by `scaffold.mjs workbench` (never overwriting). The repo checks itself: its `tools/` (token generator, gates, parity) run without the plugin. The plugin side adds only the scaffold step, the generators of PROJECT/DESIGN/flow-spec (pure functions in `scripts/lib/workbench-docs.mjs`), the instructions (references/flow.md, references/storybook.md, SKILL steps 4–6) and tests.

**Tech Stack (template, exact pins — verified together in a spike on 2026-10-13: install 22 s, typecheck/lint/stylelint/build/story-tests/storybook-build green, a planted a11y error caught, system Chrome used):** react 19.3.0, react-dom 19.3.0, @types/react 19.3.0, @types/react-dom 19.3.0, typescript 5.9.3 (typescript-eslint supports < 6.1), vite 7.3.7, @vitejs/plugin-react 5.2.0, storybook / @storybook/react-vite / @storybook/addon-a11y / @storybook/addon-docs / @storybook/addon-vitest / storybook-addon-pseudo-states 10.6.2, vitest 4.1.11, @vitest/browser-playwright 4.1.11, playwright 1.62.1, eslint 9.39.5, @eslint/js 9.39.5, typescript-eslint 8.71.2, eslint-plugin-jsx-a11y 6.10.2, eslint-plugin-react-hooks 7.1.1, globals 17.13.0, stylelint 16.26.1, stylelint-declaration-strict-value 1.12.1.

`scripts/tokens.mjs`: next to `PLUGIN_VERSION` compute
```js
import { createHash } from 'node:crypto';
const PLUGIN_HASH = (() => {
  const dir = join(import.meta.dirname);
  const files = [...readdirSync(dir).filter((f) => f.endsWith('.mjs')).map((f) => join(dir, f)), ...readdirSync(join(dir, 'lib')).filter((f) => f.endsWith('.mjs')).map((f) => join(dir, 'lib', f))].sort();
  const h = createHash('sha256');
  for (const f of files) h.update(f.slice(dir.length)).update('\0').update(readFileSync(f));
  return h.digest('hex').slice(0, 12);
})();
```
and add `hash: PLUGIN_HASH` to both instrument entries. (`readdirSync`, `readFileSync`, `join` are already imported there; add only `createHash`.)

`templates/workbench/src/App.tsx`:
```tsx
// One route per screen of the product: #/<screen name as captured> — the route tools/parity.mjs opens for it.
import { useEffect, useState } from 'react';
import { screens } from './screens';

const current = () => decodeURIComponent(window.location.hash.replace(/^#\/?/, '').split('?')[0]);

export function App() {
  const [id, setId] = useState(current);
  useEffect(() => {
    const on = () => setId(current());
    window.addEventListener('hashchange', on);
    return () => window.removeEventListener('hashchange', on);
  }, []);
  const Screen = screens[id];
  return Screen ? <Screen /> : <ScreenIndex />;
}

// Not a product screen: the list a designer opens at the root. Browser-default styles on purpose (no tokens needed).
function ScreenIndex() {
  const ids = Object.keys(screens);
  return (
    <main>
      <h1>Screens</h1>
      {ids.length ? (
        <ul>
          {ids.map((i) => (
            <li key={i}>
              <a href={`#/${encodeURIComponent(i)}`}>{i}</a>
            </li>
          ))}
        </ul>
      ) : (
        <p>No screens yet. The build loop adds them (plan/IMPLEMENTATION_PLAN.md).</p>
      )}
    </main>
  );
}
```

```js
#!/usr/bin/env node
// extraction/tokens.json (+ the designer's decisions) -> the token layer every style in this repo reads:
//   src/tokens/<group>.css   one custom property per token, its label and evidence in a comment
//   src/tokens/canvas.css    the product's own page background, text colour and font (<body> as measured)
//   src/tokens/index.css     imports them all
//   src/tokens/tokens.json   the same, compact, for Storybook's Foundations pages and the gates
//   src/foundations/Foundations.stories.tsx   one story per group that exists
// Generated — never edit them: `npm run check:tokens` fails on a hand edit. A new or changed value goes into
// extraction/canon/decided.tokens.json (with a dated reason); the extraction tool rebuilds tokens.json; then `npm run tokens`.
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, join, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

const EXT = 'co.eleken.ds';
export const HEADER = '/* Generated by tools/tokens-css.mjs — do not edit (npm run check:tokens) */';
const GROUP_OF = { color: 'color', spacing: 'space', fontSize: 'type', lineHeight: 'type', fontWeight: 'type', fontFamily: 'type', letterSpacing: 'type', radius: 'radius', shadow: 'shadow', borderWidth: 'border', duration: 'motion', easing: 'motion' };
const GROUPS = ['color', 'space', 'type', 'radius', 'shadow', 'border', 'motion', 'other'];
const STORY = { color: 'Colors', space: 'Spacing', type: 'Typography', radius: 'Radius', shadow: 'Shadows', border: 'Borders', motion: 'Motion', other: 'Other' };

const readJson = (f) => (existsSync(f) ? JSON.parse(readFileSync(f, 'utf8')) : null);
const aliasOf = (v) => /^\{(.+)\}$/.exec(String(v))?.[1] ?? null;

function format(t, value) {
  if (typeof value === 'number') return t.$type === 'dimension' ? `${value}px` : String(value);
  if (Array.isArray(value)) return t.$type === 'cubicBezier' ? `cubic-bezier(${value.join(', ')})` : value.join(', ');
  if (value && typeof value === 'object') return value.value != null && value.unit ? `${value.value}${value.unit}` : JSON.stringify(value);
  return String(value);
}

export function generate({ root = process.cwd() } = {}) {
  const doc = readJson(join(root, 'extraction', 'tokens.json'));
  if (!doc || !Object.keys(doc.tokens ?? {}).length) return { error: 'no tokens in extraction/tokens.json — run the extraction first' };
  const decisions = readJson(join(root, 'extraction', 'decisions.json')) ?? {};
  const rename = new Map((decisions.tokens ?? []).filter((x) => x.name && x.name !== x.id).map((x) => [x.id, x.name]));
  const dropped = new Map();
  for (const x of decisions.excluded ?? []) if (!x.include) for (const k of x.tokens ?? []) dropped.set(k, `prototype-only: ${x.what ?? x.id}`);
  const problems = [];
  const T = doc.tokens;
  const nameOf = (k) => rename.get(k) ?? String(T[k]?.$extensions?.[EXT]?.cssVar ?? `--${k}`).replace(/^--/, '');
  // a token that refers to a dropped one is dropped too (reported), so nothing points at a variable that is not there
  let changed = true;
  while (changed) {
    changed = false;
    for (const [k, t] of Object.entries(T)) {
      if (dropped.has(k)) continue;
      const css = String(t.$extensions?.[EXT]?.css ?? '');
      const refs = [aliasOf(t.$value), ...[...css.matchAll(/var\(\s*--([A-Za-z0-9_-]+)/g)].map((m) => Object.keys(T).find((x) => nameOf(x) === m[1] || x === m[1]) ?? null)].filter(Boolean);
      const bad = refs.find((r) => dropped.has(r));
      if (bad) { dropped.set(k, `refers to a dropped token: ${bad}`); problems.push(`${k} refers to a dropped token (--${nameOf(bad)}): left out too`); changed = true; }
    }
  }
  const valueCss = (k, t, which = 'base') => {
    const x = t.$extensions?.[EXT] ?? {};
    const raw = which === 'dark' ? t.$modes?.dark : t.$value;
    const a = aliasOf(raw);
    if (a) return `var(--${nameOf(a)})`;
    if (which === 'base' && x.css && !/channels$/.test(x.cssForm ?? '')) return String(x.css);
    return format(t, raw);
  };
  const usesOf = (t) => {
    const n = t.$provenance?.counters?.nodes, r = t.$extensions?.[EXT]?.usage?.rules;
    return n != null ? `on ${n} elements` : r ? `in ${r} style rules` : null;
  };
  const rows = [];
  for (const k of Object.keys(T).sort()) {
    if (dropped.has(k)) continue;
    const t = T[k], x = t.$extensions?.[EXT] ?? {};
    const group = GROUP_OF[x.role] ?? 'other';
    const renamedFrom = rename.has(k) ? k : undefined;
    const label = t.$provenance?.label ?? 'unknown';
    if (!['measured', 'derived', 'decided'].includes(label)) problems.push(`${k} has no label (measured / derived / decided)`);
    const proposed = label !== 'decided' && !t.$provenance?.authoredName;
    const dark = t.$modes?.dark != null && t.$modes.dark !== t.$value ? valueCss(k, t, 'dark') : undefined;
    rows.push({ key: k, name: nameOf(k), cssVar: `--${nameOf(k)}`, group, role: x.role ?? 'other', value: valueCss(k, t), dark, label,
      roleLabel: x.roleProvenance?.label, evidence: String(t.$provenance?.evidence ?? '').slice(0, 300), uses: usesOf(t) ?? undefined, renamedFrom, proposed });
  }
  const comment = (r) => [r.label, r.uses, r.proposed ? (r.renamedFrom ? `proposed name ${r.renamedFrom}, renamed by the designer` : 'proposed name') : null].filter(Boolean).join(' · ');
  const files = {};
  const present = GROUPS.filter((g) => rows.some((r) => r.group === g));
  for (const g of present) {
    const rs = rows.filter((r) => r.group === g);
    const lines = [HEADER, ':root {', ...rs.map((r) => `  ${r.cssVar}: ${r.value}; /* ${comment(r)} */`), '}'];
    const darks = rs.filter((r) => r.dark);
    if (darks.length) {
      const body = darks.map((r) => `    ${r.cssVar}: ${r.dark};`);
      lines.push('', '@media (prefers-color-scheme: dark) {', '  :root:not([data-theme="light"]) {', ...body, '  }', '}', '', ':root[data-theme="dark"] {', ...body.map((l) => l.slice(2)), '}');
    }
    files[`src/tokens/${g}.css`] = lines.join('\n') + '\n';
  }
  const cv = doc.$meta?.platform?.canvas;
  const decl = (prop, part) => {
    if (!part) return null;
    if (part.token && !dropped.has(part.token) && T[part.token]) return `  ${prop}: var(--${nameOf(part.token)});`;
    return part.value ? `  ${prop}: ${part.value}; /* measured, no token holds it */` : null;
  };
  files['src/tokens/canvas.css'] = [HEADER, '/* <body> as the product paints it (computed style, most common over the captured screens) */', 'body {',
    ...[decl('background-color', cv?.background), decl('color', cv?.color), decl('font-family', cv?.fontFamily), decl('font-size', cv?.fontSize), decl('line-height', cv?.lineHeight), decl('font-weight', cv?.fontWeight)].filter(Boolean), '}'].join('\n') + '\n';
  files['src/tokens/index.css'] = [HEADER, ...present.map((g) => `@import './${g}.css';`), "@import './canvas.css';"].join('\n') + '\n';
  const product = doc.$meta?.product ?? 'Product';
  files['src/tokens/tokens.json'] = JSON.stringify({ _generated: 'by tools/tokens-css.mjs — do not edit (npm run check:tokens)', product, themes: { dark: rows.some((r) => r.dark) },
    tokens: rows.map(({ proposed, ...r }) => r), dropped: [...dropped].map(([key, reason]) => ({ key, reason })) }, null, 1) + '\n';
  files['src/foundations/Foundations.stories.tsx'] = [
    '// Generated by tools/tokens-css.mjs — do not edit (npm run check:tokens)',
    "import type { Meta, StoryObj } from '@storybook/react-vite';",
    "import { TokenTable } from './TokenTable';",
    '',
    "const meta = { title: 'Foundations/Tokens', component: TokenTable } satisfies Meta<typeof TokenTable>;",
    'export default meta;',
    'type Story = StoryObj<typeof meta>;',
    '',
    ...present.map((g) => `export const ${STORY[g]}: Story = { args: { group: '${g}' } };`),
  ].join('\n') + '\n';
  return { files, problems, product };
}

const isMain = (() => { try { return resolve(process.argv[1] ?? '') === fileURLToPath(import.meta.url); } catch { return false; } })();
if (isMain) {
  const r = generate();
  if (r.error) { console.error(r.error); process.exit(2); }
  for (const [rel, content] of Object.entries(r.files)) { mkdirSync(dirname(rel), { recursive: true }); writeFileSync(rel, content); }
  for (const p of r.problems) console.error(`tokens: ${p}`);
  console.log(`tokens: ${Object.keys(r.files).length} files written for ${r.product}`);
}
```

```tsx
// The Foundations pages: every token of one group, as the product paints it, with how it was obtained.
import data from '../tokens/tokens.json';
import styles from './TokenTable.module.css';

type Row = { key: string; name: string; cssVar: string; group: string; role: string; value: string; dark?: string; label: string; roleLabel?: string; evidence: string; uses?: string; renamedFrom?: string };
const rows = (data as { tokens: Row[] }).tokens;

function Sample({ r }: { r: Row }) {
  const v = `var(${r.cssVar})`;
  if (r.role === 'color') return <span className={styles.swatch} style={{ background: v }} />;
  if (r.group === 'type' && r.role === 'fontSize') return <span style={{ fontSize: v }}>Aa</span>;
  if (r.group === 'type' && r.role === 'fontFamily') return <span style={{ fontFamily: v }}>Aa Бб 123</span>;
  if (r.group === 'type' && r.role === 'fontWeight') return <span style={{ fontWeight: v }}>Aa</span>;
  if (r.group === 'radius') return <span className={styles.box} style={{ borderRadius: v }} />;
  if (r.group === 'shadow') return <span className={styles.box} style={{ boxShadow: v }} />;
  if (r.group === 'space') return <span className={styles.bar} style={{ width: v }} />;
  return null;
}

export function TokenTable({ group }: { group: string }) {
  const list = rows.filter((r) => r.group === group);
  return (
    <table className={styles.table}>
      <thead>
        <tr><th scope="col">Sample</th><th scope="col">Token</th><th scope="col">Value</th><th scope="col">How it was obtained</th></tr>
      </thead>
      <tbody>
        {list.map((r) => (
          <tr key={r.key}>
            <td><Sample r={r} /></td>
            <td><code>{r.cssVar}</code>{r.renamedFrom ? <div className={styles.note}>renamed from {r.renamedFrom}</div> : null}</td>
            <td><code>{r.value}</code>{r.dark ? <div className={styles.note}>dark: <code>{r.dark}</code></div> : null}</td>
            <td><span className={styles[r.label] ?? styles.badge} title={r.evidence}>{r.label}</span>{r.uses ? <div className={styles.note}>{r.uses}</div> : null}{r.roleLabel === 'derived' ? <div className={styles.note}>purpose derived</div> : null}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

```js
// Gate 2, the part stylelint cannot see: raw colours and sizes written in TypeScript (inline styles, string literals).
// A real one-off the product has: put `// ds-allow: <why>` on that line — the reason is reviewed with the PR.
import { readdirSync, readFileSync } from 'node:fs';
import { join, relative } from 'node:path';

const ROOT = process.cwd();
const files = [];
(function walk(d) {
  for (const e of readdirSync(d, { withFileTypes: true })) {
    const p = join(d, e.name);
    if (e.isDirectory()) { if (!/^(foundations|tokens)$/.test(e.name) || d !== join(ROOT, 'src')) walk(p); continue; }
    if (/\.(ts|tsx)$/.test(e.name) && !/\.stories\.tsx?$/.test(e.name)) files.push(p);
  }
})(join(ROOT, 'src'));

const HEX = /(['"`])[^'"`\n]*#[0-9a-fA-F]{3,8}\b[^'"`\n]*\1/;
const FN = /(['"`])[^'"`\n]*\b(rgba?|hsla?|oklch|oklab|lab|lch|hwb)\(/;
const ALLOW = /\/\/\s*ds-allow:\s*\S/;
const findings = [];
for (const f of files) {
  const lines = readFileSync(f, 'utf8').split('\n');
  let inStyle = 0;
  lines.forEach((line, i) => {
    const at = `${relative(ROOT, f)}:${i + 1}`;
    if (ALLOW.test(line)) return;
    if (HEX.test(line)) findings.push(`${at}: a raw colour (hex)`);
    else if (FN.test(line)) findings.push(`${at}: a raw colour function`);
    const startsStyle = /style=\{\{/.test(line);
    if (startsStyle || inStyle) {
      const seg = startsStyle ? line.slice(line.indexOf('style={{')) : line;
      for (const m of seg.matchAll(/:\s*(-?\d*\.?\d+)\s*[,}]/g)) if (Number(m[1]) !== 0) findings.push(`${at}: a raw number in an inline style (${m[1]})`);
      for (const m of seg.matchAll(/:\s*(['"`])([^'"`]*)\1/g)) if (/\d(px|rem|em)\b/.test(m[2]) && !/^\s*var\(/.test(m[2])) findings.push(`${at}: a raw length in an inline style (${m[2]})`);
      const opens = (seg.match(/\{/g) || []).length, closes = (seg.match(/\}/g) || []).length;
      inStyle = Math.max(0, inStyle + opens - closes);
    }
  });
}
for (const x of findings) console.log(`${x} — use a token (var(--…)), or write NEEDS-TOKEN in plan/progress.md and ask the designer`);
```

```js
// One browser for the checks: the installed Google Chrome when there is one, otherwise Playwright's Chromium
// (npx playwright install chromium). `playwright` in a product repo; `playwright-core` when the plugin runs this file.
import { existsSync } from 'node:fs';

const candidates = () => [process.env.CHROME_PATH, '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome', '/usr/bin/google-chrome', 'C:/Program Files/Google/Chrome/Application/chrome.exe'].filter(Boolean);

export async function launch({ headless = true } = {}) {
  const { chromium } = await import('playwright').catch(() => import('playwright-core'));
  const tried = [];
  for (const executablePath of candidates().filter((p) => existsSync(p))) {
    try { return await chromium.launch({ headless, executablePath }); } catch (e) { tried.push(`${executablePath}: ${String(e.message).split('\n')[0]}`); }
  }
  try { return await chromium.launch({ headless }); } catch (e) {
    tried.push(`bundled Chromium: ${String(e.message).split('\n')[0]}`);
    throw new Error(`No browser for the checks. Install Google Chrome, or run: npx playwright install chromium\n${tried.join('\n')}`);
  }
}
```

```js
#!/usr/bin/env node
// The seven gates. Work counts as done only when `node tools/gates.mjs all` passes (AGENTS.md rule 9).
//   fast    every quick gate (the Stop hook runs these)      all     fast + build + stories + Storybook + parity
//   parity  build, then the flow screens against the captures of the app
import { spawnSync } from 'node:child_process';
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

const mode = process.argv[2] ?? 'fast';
const npm = (script) => ({ cmd: process.platform === 'win32' ? 'npm.cmd' : 'npm', args: ['run', '-s', script] });
const FAST = [
  ['lint (code)', npm('lint')], ['tokens only (styles)', npm('lint:css')], ['tokens only (TypeScript)', npm('check:inline')],
  ['types', npm('typecheck')], ['token layer', npm('check:tokens')], ['stories exist', npm('check:stories')],
];
const SLOW = [['build', npm('build')], ['stories render + accessibility', npm('test:stories')], ['Storybook builds', npm('build-storybook')]];

function flowScreens() {
  const f = join(process.cwd(), 'extraction', 'decisions.json');
  return existsSync(f) ? JSON.parse(readFileSync(f, 'utf8')).flow?.screens ?? [] : [];
}
function parityGate() {
  const screens = flowScreens();
  if (!screens.length) return { ok: false, out: 'no screens in the test flow yet (extraction/decisions.json flow.screens) — choose them at the checkpoint' };
  const b = spawnSync(npm('build').cmd, npm('build').args, { encoding: 'utf8' });
  if (b.status !== 0) return { ok: false, out: `${b.stdout}${b.stderr}` };
  const p = spawnSync(process.execPath, ['tools/parity.mjs', '.', '--serve', 'dist', ...screens.flatMap((s) => ['--only', s])], { encoding: 'utf8' });
  return { ok: p.status === 0, out: `${p.stdout}${p.stderr}` };
}
const plan = mode === 'parity' ? [['similarity to the app', parityGate]] : mode === 'all' ? [...FAST, ...SLOW, ['similarity to the app', parityGate]] : FAST;
let failed = 0;
for (const [name, run] of plan) {
  const r = typeof run === 'function' ? run() : (() => { const x = spawnSync(run.cmd, run.args, { encoding: 'utf8' }); return { ok: x.status === 0, out: `${x.stdout ?? ''}${x.stderr ?? ''}` }; })();
  console.log(`${r.ok ? '✓' : '✗'} ${name}`);
  if (!r.ok) { failed++; for (const l of r.out.trimEnd().split('\n').slice(-30)) console.log(`    ${l}`); }
}
console.log(`gates: ${plan.length - failed} passed, ${failed} failed${failed ? ' — see above' : ''}`);
process.exit(failed ? 1 : 0);
```
