# ds-from-app — плагін для Claude Code

Бере живий застосунок за посиланням і з нього будує дизайн-систему та репозиторій-Верстак. Від початку до кінця:

1. **Збирає.** Відкриває застосунок у вашому Google Chrome, знімає екрани й читає з них кольори, відступи, шрифти,
   радіуси, компоненти й переходи. Кожне значення має позначку, як його отримали: виміряно, виведено чи вирішено
   людиною. У застосунку нічого не змінює: форм не надсилає, записи блокує, пароль за вас не вводить.
2. **Показує сторінку для рішень.** Ви обираєте тестовий флоу, перевіряєте назви й відмічаєте, що лише частина
   прототипу (перемикачі ролей, демо-панелі), а не самого продукту.
3. **Будує Верстак.** Токени як змінні CSS, Storybook, опис тестового флоу і сім перевірок (`npm run check` друкує
   десять кроків).
4. **Відтворює тестовий флоу** задача за задачею і порівнює із застосунком. Ви бачите обидва поруч, з переліком
   того, що збігається, що ні й чому.

Поки флоу не відтворено, токени вважаються неперевіреними.

## Встановити (один раз)

```
git clone <посилання на репозиторій плагіна> ~/ds-from-app
claude plugin marketplace add ~/ds-from-app
claude plugin install ds-from-app@ds-from-app
```

Потрібні Node 22+ і Google Chrome. Відкрийте нову сесію Claude Code — команда `/ds-from-app` зʼявиться.

Ставте з окремої копії репозиторію, а не з теки, у якій плагін змінюють: установка копіює теку цілком, разом із
робочими файлами. Так перевірено на чистій копії в окремому налаштуванні Claude Code: плагін став, його залежності
поставились самі, перевірка середовища пройшла.

## Користуватися

Одна команда:

```
/ds-from-app https://app.example.com
/ds-from-app continue        # у теці проєкту, щоб продовжити
```

**Чотири місця, де Claude чекає на вас:**

1. **Підготовка.** Чи треба входити в акаунт (входите ви самі у вікні браузера), чи є темна тема, де тримати проєкт.
2. **Сторінка рішень.** Тестовий флоу, назви, що з побаченого є лише прототипом.
3. **План тестового флоу.** Claude показує план простими словами й чекає вашого «так»; потім кожну задачу зливає в
   основну гілку лише після вашого «так, зливай».
4. **Приймання.** Застосунок і наш прототип поруч (`extraction/compare.html`): що збігається, що ні й чому, чого
   не вдалося перевірити.

**Нова сесія.** Коли Верстак готовий, Claude попросить відкрити Claude Code у теці Верстака (нова сесія там, дозвольте
довіряти теці) і сказати «склади план». Правила, перевірки й навички Верстака підхоплюються лише в сесії, запущеній
у ньому. Далі кожна задача флоу — окрема нова сесія.

**Скільки це займає.** На пілоті (застосунок із двох екранів; свіжа сесія Claude лише з інструкцією плагіна, дизайнер
один раз підказав, що в меню два екрани): близько 45 хвилин роботи Claude, плюс час на ваші відповіді.

## Для того, хто змінює плагін

`npm test` — швидкі перевірки; `npm run selftest` — інструменти проти синтетичних застосунків із відомою відповіддю
(кілька хвилин, відкриває браузер).
