# Старт: дизайн-система й Верстак із вашого продукту

Ця сторінка — для першого запуску. Займе 5 хвилин підготовки, далі Claude веде вас сам і зупиняється там, де
потрібне ваше рішення.

## 1. Що потрібно

- Claude Code (у терміналі чи в десктоп-апці).
- Node 22 або новіший (перевірити: `node -v`), Google Chrome, git.
- Акаунт у продукті, у який ви входите самі. Найкраще — тестовий акаунт, якому видно потрібні екрани.

## 2. Встановити плагін (один раз)

У терміналі:

```
claude plugin marketplace add DShkiaruk/ds-from-app
claude plugin install ds-from-app@ds-from-app
```

## 3. Запустити

1. Створіть порожню теку з назвою латиницею (наприклад, `~/ds-start`) і відкрийте Claude Code саме в ній —
   нова сесія.
2. Напишіть, підставивши посилання на ваш продукт:

```
/ds-from-app https://ваш-продукт.com
```

3. Claude поставить кілька запитань. Можна відповісти одним повідомленням — скопіюйте й заповніть:

```
Так, у продукт треба входити — відкрий вікно браузера, я увійду сама.
Продукт викидає, якщо закрити вкладку або перезавантажити сторінку: <так / ні / не знаю>.
Темна тема: <є / немає>.
Продукт називається <Назва>.
Проєкт тримай у ~/<назва-латиницею>-workbench.
Справжні дані людей у продукті: <є / немає>.
Тестовий флоу від початку до кінця: <екран → дія → екран → …>, наприклад «список проєктів → відкрити проєкт →
вкладка Налаштування».
Стани, які флоу має показати: <наприклад, відкритий діалог «Новий проєкт», порожній список, вкладка «Історія»>.
Глибші стани, до яких треба дійти ланцюжком: <наприклад, «Налаштування → вкладка Додатково → меню Експорт»>.
```

**Що Claude проклікає сам, а що ні.**
- **Сам:** натискає кожен безпечний елемент на екранах флоу (меню, вкладки, рядки таблиць, кнопки) і йде на кожен
  новий екран, до якого вони ведуть, — скільки завгодно кроків углиб. Меню чи діалог, що відкривається поверх
  екрана, він розкриває і натискає все всередині; знімає наведення, фокус і натискання.
- **Коли назвете:** стан, захований глибше — діалог, відкритий із діалогу, пункт меню всередині вкладки. Сам він
  такий шар не розкриває (кожен рівень множить кількість натискань і навантаження на продукт), але пройде до нього
  ланцюжком кліків будь-якої довжини, якщо ви його назвете: «Налаштування → вкладка Додатково → меню Експорт».
- **Не може:** вводити текст (заповнена форма, результат пошуку), натискати «Зберегти», «Видалити», «Надіслати»,
  побачити стан, якого немає в даних акаунта (порожній список, помилка). Такі стани він позначить як не досягнуті, а
  не намалює навмання. Якщо стан важливий — підготуйте акаунт так, щоб він існував (наприклад, порожній проєкт для
  порожнього стану), і скажіть про нього в першому повідомленні.

## 4. Вхід у продукт

- Claude відкриє окреме вікно Chrome зі сторінкою входу. **Увійдіть самі**: логін, пароль, код підтвердження.
  Claude їх не вводить.
- Коли після входу відкриється перший екран продукту, вікно закриється само. Сесія збережеться у вас на комп'ютері
  (у теці `~/.ds-from-app/sessions`), поза проєктом: у репозиторій вона не потрапляє. На вхід є 10 хвилин.
- Якщо вхід через Google чи Microsoft і вікно не пускає далі (пише, що браузер небезпечний), спробуйте вхід поштою й
  паролем або тестовий акаунт.
- Якщо замість продукту з'явиться перевірка «чи ви не робот» від хостингу (Vercel, Cloudflare), Claude зупиниться і
  скаже, що можна зробити.
- Сесія з часом закінчується. Якщо Claude скаже, що бачить сторінку входу замість екрана, увійдіть ще раз — він
  відкриє вікно знову.
- Якщо продукт викидає вас, щойно закрити вкладку чи перезавантажити сторінку, напишіть «так» у цьому рядку першого
  повідомлення. Тоді Claude працюватиме прямо у вікні, де ви увійшли, і не перезавантажуватиме його: воно лишиться відкритим, і ви бачитимете, як у ньому змінюються сторінки. Не закривайте його й не клацайте
  в ньому, поки Claude знімає; коли зйомка закінчиться, він закриє вікно сам.

**Що Claude робить у продукті:** лише дивиться. Знімає екрани й натискає безпечні елементи — меню, вкладки, рядки
таблиць, — щоб побачити переходи. Запити, які щось зберігають, видаляють чи надсилають, заблоковано; кнопки на кшталт
«Видалити» чи «Вийти» він не натискає; форми не відправляє.

## 5. Сторінка рішень

Коли знімання закінчиться, Claude відкриє в браузері сторінку рішень. На ній ви:

- обираєте екрани тестового флоу і їхній порядок (галочки — у тому порядку, в якому ставите), і даєте флоу назву;
- перевіряєте запропоновані назви токенів (можна лишити як є);
- відмічаєте, що існує лише в прототипі чи демо, а не в продукті;
- вирішуєте про змінні, які продукт оголошує, але ніде не вживає;
- натискаєте «Готово» і повертаєтеся до Claude.

## 6. Далі — у Верстаку

Claude збудує Верстак і попросить відкрити Claude Code **в його теці** — нова сесія. Далі кожна фраза — у новій сесії:

| Ви кажете | Що відбувається |
|---|---|
| «склади план» | план задач простими словами; Claude чекає вашого «так» |
| «зроби наступну задачу» | одна задача на окремій гілці, з перевірками |
| «так, зливай» | задача потрапляє в основну гілку |
| «чи готово?» | усі перевірки і звіт: що збігається з продуктом, чого бракує |
| «готуй передачу» | документ для клієнта; комітить лише після вашого «так» |

Подивитися результат у теці Верстака: `npm run dev` (прототип) і `npm run storybook` (компоненти й токени).

Коли значення бракує, Claude не вигадує його: питає вас. Що він питає — це рішення дизайнера (як колір, розмір чи
стан мають виглядати); відповідайте як дизайнер, технічні деталі він вирішує сам.

## 7. Скільки це займає

На тестових прогонах флоу на 2–4 екрани зайняв від 45 до 85 хвилин роботи Claude і 10–13 сесій, плюс час на ваші
відповіді. Закладайте пів дня з перервами.

## 8. Оновлення

Якщо вийшла нова версія, а робота вже йде:

1. У Terminal:

```
claude plugin marketplace update ds-from-app
claude plugin update ds-from-app@ds-from-app
```

2. Відкрийте нову сесію Claude Code **в теці проєкту** — тій, що ви назвали в першому повідомленні
   (`~/<назва>-workbench`). Якщо вже працюєте у Верстаку, то в теці Верстака.
3. Напишіть `/ds-from-app continue`. Claude продовжить з того місця, де зупинився. Якщо продукт викидає, щойно
   закрити вкладку чи перезавантажити сторінку, допишіть другим рядком: «Продукт викидає, якщо закрити вкладку чи
   перезавантажити сторінку, — працюй в одному вікні й без перезавантажень».

Що змінилося в кожній версії — у [CHANGES.md](CHANGES.md).

## 9. Якщо щось не так

- Claude застряг або питає щось незрозуміле — напишіть «не знаю, вирішуй сам» або опишіть, що бачите.
- Помилка інструмента — опишіть у [issues](https://github.com/DShkiaruk/ds-from-app/issues): що ви написали, що
  відповів Claude, посилання на продукт (якщо можна).
- Повна документація: [README](README.md).
