# Plan mode

Read AGENTS.md, PROJECT.md, DESIGN.md, FRONTEND.md, specs/ and plan/progress.md. Compare them with src/.
Write plan/IMPLEMENTATION_PLAN.md: a prioritized list of small tasks (one screen, or one component with its story,
per task), each with: what to build, which spec section it serves, which gate proves it, and the NEEDS-* it already
knows of. Plan only — do not implement anything. End by asking the designer to read the plan and say OK.
